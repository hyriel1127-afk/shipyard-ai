인코딩 UTF-8(BOM 없음), 줄바꿈 `\n`.

```text
생성 시각: 2026-11-13 14:05 KST

- 본문:
> 첫 줄
> 둘째 줄
```

## 질문에 답변이 없을 때

해당 질문 항목 끝에 아래 한 줄을 쓴다(`### 답변 N` 대신).

```text
### 답변 없음
```

## 질문이 하나도 없을 때

```text
생성 시각: 2026-11-13 14:05 KST

내보낼 질문이 없습니다
```

제목 줄(`# QnA 스냅샷`)과 질문 항목은 쓰지 않는다. 생성 시각 줄 외에는 문구 한 줄뿐이다(둘 사이 빈 줄 1개).

## 규칙

1. **생성 시각**: 질문이 있든 없든 파일의 **첫 줄**은 `생성 시각: YYYY-MM-DD HH:mm KST`이다. 질문이 있을 때는 빈 줄 1개 뒤에 `# QnA 스냅샷` 제목이 온다.
2. **항목 경계**: 실제 질문 경계는 줄 시작이 `## 질문 <번호>`인 줄뿐이다. 제목·본문은 모든 줄 앞에 `>`를 붙이므로 본문 안의 `##`, `---`, 코드 펜스는 경계로 해석되지 않는다.
3. **빈 줄**: 본문의 빈 줄은 `>`로 쓴다(뒤 공백 없음). 그 외 줄은 `> ` 뒤에 원문을 붙인다.
4. **날짜**: 모든 날짜·시각은 KST, `YYYY-MM-DD HH:mm`.
5. **순서**: 질문은 번호 오름차순, 답변은 등록 순.
6. **제외**: 사번·이름·작성자 식별 정보는 어떤 형태로도 쓰지 않는다.
7. **가공 금지**: 제목·본문은 원문 그대로이며 잘라내지 않는다.
