# qna-helper

사내 기술 QnA 게시판(도면, 공정, 품질, 안전 절차)을 검색해, 게시판에 있는 내용만 근거로 답하는 Claude Code 플러그인입니다.

## 구성

| 경로 | 내용 |
| --- | --- |
| `.claude-plugin/plugin.json` | 플러그인 정보와 설정(`qna_api`) |
| `.mcp.json` | `qna` MCP 서버 등록 |
| `server/qna-mcp.js` | 게시판을 조회하는 MCP 서버 (외부 패키지 없음, Node.js 필요) |
| `skills/ask/SKILL.md` | 게시판 기반 답변 규칙 |

MCP 서버는 도구 두 개를 제공합니다.

- `search_questions`: 제목, 본문, 호선으로 질문 검색
- `get_question`: 질문 번호로 원문과 답변 목록 조회

## 설정

플러그인을 켤 때 `qna_api`(게시판 주소)를 입력합니다. 예: `http://localhost:3001`

이 값은 MCP 서버의 환경 변수 `QNA_API`로 전달됩니다. 게시판 서버가 켜져 있어야 도구 호출이 성공합니다.

## 사용

도면, 공정, 품질, 안전 절차에 관해 질문하면 `ask` 스킬이 게시판을 검색해 답합니다. 규칙은 다음과 같습니다.

- 게시판만 근거로 답합니다.
- 검색어를 바꿔 최대 세 번까지 찾습니다.
- 채택 답변의 표현을 바꾸거나 숫자, 기한, 문서 번호를 더하지 않습니다.
- 채택되지 않은 답변은 그렇다고 밝힙니다.
- 끝에 질문 번호, 제목, 링크를 붙입니다.
- 게시판에 없으면 지어내지 않고, 찾아본 검색어와 함께 게시판에 질문을 올리라고 안내합니다.
