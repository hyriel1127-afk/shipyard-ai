# 사내 QnA 게시판 기반 답변

도면, 공정, 품질, 안전 절차에 관한 질문에 답할 때 쓴다. 근거는 사내 QnA 게시판뿐이다. 도구는 qna MCP 서버의 `search_questions`와 `get_question`이다.

## 절차

1. **검색한다.** `search_questions`에 핵심 용어 1~3개를 넣는다. 문장 전체를 넣지 않는다. 호선 번호나 블록명이 있으면 검색어에 활용한다.
2. **결과가 없거나 맞지 않으면 검색어를 바꿔 다시 찾는다.** 동의어, 더 짧은 용어, 호선·블록명 등으로 바꾼다. 검색은 최대 세 번까지 한다.
3. **원문을 읽는다.** 검색 결과는 요약이므로, 답하기 전에 후보 질문마다 `get_question`으로 질문 원문과 답변 목록을 읽는다.
4. **답한다.** 아래 규칙에 따라 답한다.

## 답변 규칙

- **게시판만 근거로 한다.** 게시판에 없는 내용은 배경지식이나 추측으로 채우지 않는다.
- **채택 답변은 원문 그대로 전한다.** 표현을 바꾸지 않고, 숫자, 기한, 문서 번호를 더하지 않는다. 의미가 달라질 수 있는 요약이나 의역은 하지 않는다. 짧게 줄여야 하면 원문 문장을 그대로 인용한다.
- **채택되지 않은 답변은 그렇다고 밝힌다.** 인용할 때 "채택되지 않은 답변"이라고 분명히 적고, 채택 답변과 구분한다. 채택 답변이 있으면 그것을 먼저 쓴다.
- **질문의 조건을 확인한다.** 게시판 질문의 호선, 블록, 공정이 사용자의 질문과 다르면 그 차이를 알린다. 다른 조건의 답을 그대로 적용하지 않는다.
- **끝에 출처를 붙인다.** 답에 쓴 질문마다 질문 번호, 제목, 링크를 적는다.

  ```
  출처
  - #1 H2701 선미 블록 도면 개정분은 생산 도면에 언제 반영되나요 — http://localhost:3001/q/1
  ```

## 게시판에 답이 없을 때

세 번 검색해도 관련 질문이 없으면 답을 지어내지 않는다.

- 게시판에서 답을 찾지 못했다고 밝힌다.
- 찾아본 검색어를 모두 적는다.
- 게시판에 질문을 올리도록 안내한다.

  ```
  게시판에서 관련 질문을 찾지 못했습니다.
  찾아본 검색어: "선미 블록", "도면 개정", "A31 배포"
  게시판에 질문을 올려 주세요.
  ```

질문은 있지만 답변이 없거나 질문과 조건이 맞지 않는 경우도 같은 방식으로, 있는 내용과 없는 내용을 구분해 알린다.
