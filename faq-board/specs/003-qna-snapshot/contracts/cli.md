# 계약: 내보내기 명령

## 실행

```text
npm run snapshot
```

환경 변수(모두 선택):

| 이름 | 기본값 | 의미 |
|------|--------|------|
| `QNA_DB` | `./data/qna.sqlite` | 읽을 게시판 DB (기존 설정 재사용) |
| `QNA_SNAPSHOT_PATH` | `./data/snapshot/qna.md` | 쓸 스냅샷 파일 |

## 결과

| 상황 | 종료 코드 | 출력 (한국어) |
|------|-----------|----------------|
| 성공(질문 있음) | 0 | `스냅샷을 만들었습니다. 질문 N건, 답변 M건` |
| 성공(질문 없음) | 0 | `스냅샷을 만들었습니다. 내보낼 질문이 없습니다` |
| DB 파일이 없거나 열 수 없음 | 1 | `게시판 DB를 읽을 수 없습니다.` — 출력 파일은 만들지도 바꾸지도 않는다 |
| 폴더 생성 또는 파일 쓰기 실패 | 1 | `스냅샷 파일을 쓸 수 없습니다.` — 기존 스냅샷 유지, 임시 파일 삭제 |

## 보장

- 표준 출력에는 위 메시지 외에 `src/logger.js`의 JSON 로그 한 줄(`event`, `at`, `result`)이 함께 나온다. 메시지 검증은 포함 여부로 한다.
- 실행 전후 DB 내용이 동일하다(읽기 전용 연결).
- 출력 메시지와 로그에 이름·사번·본문을 쓰지 않는다. 로그는 `event({ event: 'snapshot_export', result: 'ok' | 'fail' })` 형태만 남긴다.
- 폴더가 없으면 만든다.
