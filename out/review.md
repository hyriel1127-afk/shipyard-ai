# 감사 반려 기록 (weekly-ship, 11/16~11/22)

규칙: 감사관(`qc-auditor`)의 반려에 따른 집계 재작업은 최대 2회. 2회 뒤에도 반려 사유가 남으면 재작업하지 않고 남은 사유를 그대로 보고한다.
감사 기준 입력은 `out/converted/` 변환본이며, 원본 `data/`와의 대조는 하지 않았다.

## 1차 감사 — 반려 1건 (재작업 1/2)

### 반려 사유
| # | 대상 | 리포트 | 감사 재계산 | 근거 |
|---|---|---|---|---|
| 1 | `out/qc-summary.md` 중복 의심 목록 | 4쌍 (조립 18/24, 32/35, 44/46, 선각 60/61) | **6쌍**. 조립 53/56, 73/78 누락 | 블록 표기만 달라 육안으로 놓침. 53/56은 `B13` vs `B-13` (11-19, H2702, 치수 검사, 합격, 15), 73/78은 `D22` vs `D22 `(후행 공백) (11-21, H2702, 용접 외관, 합격, 40) |

- 행 번호 기준: CSV 줄 번호, 조립팀은 1~2행이 제목·메모, 3행이 헤더, 데이터 4행부터.
- 집계 숫자(합격·불합격 등)는 영향 없음. 리포트가 중복을 제외하지 않았기 때문.
- 같은 블록으로 본다는 전제(표기 차이 정규화)는 감사관의 추정.

### 반려하지 않은 항목 (숫자 일치)
- 파일별 총행수 214 / 범위 내 205 / 범위 밖 9 / 합격 179 / 불합격 26 / 판정불명 0: 전부 일치
- 파일별 불합격률, 항목별 전체·불합격 건수와 행 번호: 일치
- 판정 매핑(합·OK→합격, 불·NG→불합격): 모든 값이 덮임. 근거 문서는 없어 추정으로 남음

### 반려로 처리할 수 없는 항목 (사람 결정 필요)
- 삭제예정_입력오류 시트 6행의 집계 포함 여부. 포함 시 220 / 211 / 합격 183 / 불합격 28(13.3%)
- 중복 6쌍이 이중 입력인지 별개 검사인지 (선각 60/61은 `합`과 `OK`, 둘 다 비고 '재검사')
- 재검사 행의 판정 대체 여부: 조립 57, 77, 89행 / 선각 25, 32, 52, 60, 61행
- 불합격 19행(조립 9, 선각 10)에 비고·근거 없음. 의장·도장·삭제예정 시트는 비고 열 자체가 없음
- 판정 약어 매핑 확정 (선각 팀 확인 필요)
- 소요시간 시점이 다른 '거의 중복' 후보(의장 15/24, 도장 24/25·34/38, 조립 17/22 등)는 별개 측정일 수 있어 중복으로 단정하지 않음
- 원본 xlsx·CP949 CSV와 변환본 대조는 미수행

### 조치
- 집계 에이전트에 중복 목록을 6쌍으로 갱신하도록 재작업 지시 (재작업 1/2)

## 재작업 후 재감사 — 반려 0건 (재작업 사용 1/2)

### 1차 반려 사유 처리 결과
- #1 중복 목록: **해소**. `qc-summary.md:110-117`의 6쌍이 변환 CSV와 전부 일치. 본문 `:119`는 "합계 6쌍".
- 낡은 '4쌍' 서술: 없음. `:120`의 "기존 4쌍에서 6쌍" 정정 경위 문장만 남음(정상).
- 집계 숫자 214 / 205 / 9 / 179 / 26 / 0: 1차 감사 때와 동일. 파일별 합격·불합격 재계산도 일치.

### 신규 발견 (경미, 반려 아님, 재작업 미실시)
| 대상 | 리포트 | 재계산 | 영향 |
|---|---|---|---|
| `qc-summary.md:117` 선각 60/61 판정 표기 | "합 / OK" (60행 합, 61행 OK로 읽힘) | 60행 `OK`(날짜 `11/22`), 61행 `합`(날짜 `2026-11-22`) | 행 순서만 반대. 쌍 식별·집계에 영향 없음 |

- 감사관이 반려로 분류하지 않아 재작업 횟수를 쓰지 않음. 남은 재작업 횟수 1회.
- 회의 문장에서 이 행 순서를 인용하지 않는다.

### 재감사에서 확인하지 못한 것
- 범위 밖 9행의 날짜 재계산, 항목별 건수·불합격 행 번호 재대조(1차 감사에서는 일치)
- 재작업 전후 diff (`out/`이 git 미추적, 이전 판본 없음)
- 삭제예정 시트 CSV는 재감사에서 읽지 않음

### 현재 상태
- 감사 통과. 3단계 문장(`qc-writer`)으로 진행. 사람 결정 필요 항목은 위 '반려로 처리할 수 없는 항목'이 그대로 남아 있음.
