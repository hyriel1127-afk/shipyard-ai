## 4. 데이터 처리 방식

### 4-1. 판정 정규화 (원본 값은 수정하지 않고 집계 시에만 매핑)
| 원본 값 | 매핑 | 출현 파일 / 건수 |
|---|---|---|
| `합격` | 합격 | 전 파일 (선각 16행) |
| `합격 ` (후행 공백) | 합격 | 조립팀 (공백 제거로 처리) |
| `합` | 합격 | 선각 18행 |
| `OK` | 합격 | 선각 16행 |
| `불합격` | 불합격 | 전 파일 (선각 4행: 17, 29, 44, 53) |
| `불합격 ` (후행 공백) | 불합격 | 조립팀 34행 |
| `불` | 불합격 | 선각 2행 (19, 49) |
| `NG` | 불합격 | 선각 4행 (12, 21, 24, 39) |
| 그 외 | 판정불명 | 해당 값 없음, 0건 |

- `합`, `불`, `OK`, `NG`는 약어와 영문 표기를 일반적 의미로 해석한 매핑입니다. 근거 문서는 없으며 추정입니다.
- 선각의 건수는 직접 센 값이고, 합 16 + 18 + 16 = 50이 합격 합계와 일치합니다. 조립팀은 공백 변형별 건수를 세지 않았습니다.

### 4-2. 날짜
- 확인된 형식은 `2026-11-16 00:00:00`, `2026-11-16`, `2026.11.16`, `11/16`, `20261116`입니다.
- `11/16`처럼 연도가 없는 값은 2026년으로 가정했습니다 (추정). 선각 파일에서 4가지 형식이 순환하며 섞여 있습니다.
- 의장은 `YYYYMMDD` 숫자 형식입니다. 조립·도장은 `YYYY-MM-DD 00:00:00`입니다.
- 모든 값이 해석 가능했고 해석 불가 날짜는 없었습니다.

### 4-3. 호선
